# marketplace-scripts

Набор серверных скриптов для интеграции склада с маркетплейсами (Ozon, Wildberries, Яндекс.Маркет).

Это рабочие Node.js (`.mjs`) и Python утилиты, которыми выполнялись реальные задачи бэк-офиса: синхронизация остатков и поставок, связывание карточек товара со складскими позициями, аудиты расхождений, выгрузка номенклатуры, консолидация отгрузок.

## Группы скриптов

- **Ozon** (`ozon-*`, `oz-*`, `link-ozon-*`, `remote-ozon-*`) — аудит и публикация товаров «ожидают отгрузки», консолидация поставок, связывание складских кандидатов, выгрузка атрибутов/категорий.
- **Wildberries** (`wb-*`) — аудит связок карточек, ярлыки, проверка и синхронизация поставок, подбор категорий/предметов.
- **Яндекс.Маркет** (`ym-*`) — обнаружение кампаний, аудит неотправленных заказов, диагностика, проверка активных позиций.
- **Склад/связки** (`*-warehouse-link-*`, `warehouse-candidate-audit`, `build/export-fbs-nomenclature`) — связывание карточек МП со складом и выгрузка номенклатуры.
- `db-common.mjs` — общий помощник подключения к БД (параметры из переменных окружения).

## Настройка

Доступы к API маркетплейсов и БД задаются через переменные окружения (`OZON_CLIENT_ID`/`OZON_API_KEY`, `OZON2_*`, `WB_API_TOKEN`, `YM_*`, `DB_*`, `INTERNAL_PROXY_TOKEN`). Скрипты — утилитарные, запускаются точечно под конкретную задачу: `node <script>.mjs`.

Многие скрипты в именах содержат дату (когда применялись) и рассчитаны на разовый прогон по текущему состоянию данных.
